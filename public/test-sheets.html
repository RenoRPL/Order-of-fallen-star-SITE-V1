⚠️ Setup Required

Before this works, you need to configure Google Sheets API permissions:

  1. Set up Google Cloud project with Sheets API
  2. Create service account and download JSON credentials
  3. Share your spreadsheet with the service account email
  4. Add environment variables to Netlify

See GOOGLE_SHEETS_SETUP.md for detailed instructions
